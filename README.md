# LLM Agent — تمرین ۱ (Ollama + qwen3:8b)

## نصب
1. Ollama را نصب کنید و مدل را بگیرید:
   ```
   ollama pull qwen3:8b
   ```
2. وابستگی‌های پایتون:
   ```
   pip install -r requirements.txt
   ```

## اجرا
```
python main.py --input input.json --output output.json
```
ورودی: `{"id": "...", "problem": "..."}` ، خروجی: `{"id": "...", "answer": "..."}`
(فقط پاسخ نهایی، بدون توضیح). تمام inference به‌صورت Local با Ollama انجام می‌شود و اینترنت لازم نیست.

## معماری Agent (خلاصه)
1. **Program-of-Thought:** به‌جای استدلال متنی طولانی، مدل یک برنامه‌ی کوتاه پایتون می‌نویسد که مسئله را با محاسبه / جست‌وجوی کامل حل کند و فقط پاسخ نهایی را با فرمت خواسته‌شده چاپ کند.
2. **اجرا:** برنامه در یک پروسه‌ی جدا (با timeout ۲۰ ثانیه) اجرا می‌شود و پاسخ از خروجی آن گرفته می‌شود.
3. **بازبینی (Reflection):** اگر برنامه خطا بدهد یا خروجی خالی باشد، خطا به مدل نشان داده می‌شود و یک بار اصلاح می‌کند.
4. **Fallback:** اگر باز هم جواب نگرفتیم، مدل مستقیم فقط پاسخ نهایی را می‌دهد. در صورت هر خطا، خروجی JSON معتبر تولید می‌شود.

تنظیمات: `temperature=0`، حداکثر ۴۵۰ توکن برای کد، حداکثر ۳ فراخوانی مدل برای هر مسئله. لاگ اجرا در `last_run.log` ذخیره می‌شود.
